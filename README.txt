To run code:

For environments, uncomment the environment in the main function. ONLY ONE ENVIRONMENT CAN BE RUN AT A TIME.

For algorithms, uncomment the algorithms in the main function. ONLY ONE ALGORITHM CAN BE RUN AT A TIME.

Run 

g++ -std=c++17 planner.cpp -o planner.out
./planner.out 

to get path.

For visualizations, run:

python3 visualize.py
